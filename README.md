# juan.md

Personal website built with Astro, MDX, React, and Tailwind CSS.

## Requirements

- Node.js 22.12 or newer
- pnpm 10.30.1

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
pnpm lint
pnpm format:check
```

The application source lives in `src/`, static assets in `public/`, and log content in `src/content/logs/`.

## Deployment

The site is deployed with Vercel.
